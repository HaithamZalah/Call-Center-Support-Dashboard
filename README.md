# 📞 Call Center Support Performance Dashboard

## 📌 Project Overview
This project presents an end-to-end Call Center Performance Dashboard designed to track key customer support metrics, monitor agent efficiency, and evaluate service level agreements (SLAs).

---

## 📊 Key Metrics & Insights
- **Total Calls Handled:** 1.7M calls across all projects.
- **Service Level:** Achieved **91.1%** overall service level.
- **Abandonment Rate:** Kept low at **1.32%** (Total Abandoned Calls: 23K).
- **Average Answer Time (ASA):** ~9.22 minutes overall.
- **Top Performing Agent:** Dina handled the highest call volume with **171,785 calls**.

---

## 🛠️ Tools & Technologies Used
- **Excel / Power BI:** Dashboard creation & data visualization
- **DAX & Power Query:** Data transformation and custom measures
- **KPI Dashboards:** Executive Overview, Agent Performance, and Project Analysis
